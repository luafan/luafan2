**Coverage plumbing changes (M12 requirement):**
1. `.luacov` `include` gained `"webase/"` so lines executed in the
   webase tree are counted alongside `lua/fan/`. Without this the
   entire framework was silently invisible to luacov.
2. `tests/lua/framework/coverage.lua` learned `LUAFAN_LUACOV_CONFIG`
   env-driven config bootstrap: when a child process (e.g. the
   webase server that `test_webase.lua` spawns via `fan.popen`)
   chdirs before exec, luacov's default `.luacov` lookup fails and
   silently falls back to defaults, writing stats to `CWD/luacov.
   stats.out` — invisible to the aggregator. The env var points at
   an absolute path; the hook `dofile`s it, rewrites the (relative)
   `statsfile` to absolute, and passes the table to `runner.init`.
3. `test_webase.lua` sets `LUAFAN_LUACOV_CONFIG=$ROOT/.luacov` in the
   child env AND hits a new `/__coverage_flush` fixture endpoint in
   `stop_server()`. The endpoint calls `luacov.runner.save_stats()`
   then `fan.loopbreak()` so the child exits gracefully and lua_close
   runs luacov's `__gc` anchor. Without this, `fan.popen`'s SIGTERM
   (→ SIGKILL after 10ms) skipped every luacov flush path, so the
   webase server's execution history never reached the report.
