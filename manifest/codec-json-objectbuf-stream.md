# Codec — objectbuf and stream compatibility

## fan.objectbuf

`src/codec/objectbuf.c` is a native C implementation of the LuaFan v1
section/index wire protocol. There is no Lua facade file:

- flag byte for number, U30, string, table, and boolean sections;
- little-endian D64 and U30 stream values;
- indexed table/key/value references;
- v1 boolean root encoding (`0x00` false, `0x01` true);
- cyclic and shared table references;
- `symbol(obj)` returning the v1 table `{[1]=map, [2]=map_vk, [3]=index}`
  (indices assigned over sorted strings, then numbers, then U30 values);
- `sample(value[, limit])` frequency helper.

Both `require("fan.objectbuf")` and `require("fan").objectbuf` resolve to the
same C table. Symbols reduce repeated values and preserve the v1 compressed
message workflow used by worker and TCP objectbuf frames.

Coverage:
- `tests/lua/test_objectbuf.lua` — v1 golden byte vectors, symbol
  compression, cycles, shared subgraphs, entry-point parity.
- `tests/lua/test_objectbuf_v1_interop.lua` — decodes vectors produced by the
  genuine LuaFan v1 runtime. `tests/fixtures/objectbuf/v1_vectors.lua` is
  generated by `tests/fixtures/objectbuf/probe_emit.lua` inside the
  `luafan/luafan-ubuntu` image.
- `tests/lua/test_integration.lua` / `tests/lua/test_worker.lua` — framed
  transport and worker messages.

Verified on arm1 (aarch64, `luafan2-ci:local`): v1 bytes decoded by the v2
codec and v2 bytes decoded by the v1 runtime, in both plain and symbol form
(60 records / 120 checks per direction; byte-exact for stable records),
under normal and ASan builds.

## fan.stream

`fan.stream` retains the v1 little-endian byte protocol: U/S integer widths,
U30 LEB128, D64, raw bytes, and U30-prefixed strings. Its API additionally
provides v2 introspection and line helpers; short-read errors are surfaced as
`nil, "eof"` by the public v2 API.
