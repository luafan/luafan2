LuaFan runtime

A small, fast Lua web service.

This container is running the LuaFan web architecture: a native event loop, a Lua application layer, and a streaming HTTP server designed for APIs, services, and static content.

default service · port 2201

How a request flows

client→fan.httpd→core.lua→route / webfile→response

Runtime layers

Native foundation

fan and fan.so provide the Lua VM, libevent loop, TCP/TLS, JSON, compression, and database bindings.

HTTP service

fan.httpd accepts connections and supports the Lua HTTP backend, streaming replies, WebSocket integration, and request metadata.

Application core

/root/core.lua loads configuration, services, mappings, routes, and the HTTP application on startup.

Application files

Put handlers in handle/, background services in service/, mappings in mapping/, and static content in web/.

Bring your application

The bundled page is only a landing page. Mount your own application directories at /root or override the default command with another Lua script.

docker run --rm -p 2201:2201 \
  -v "$PWD/handle:/root/handle" \
  -v "$PWD/service:/root/service" \
  -v "$PWD/mapping:/root/mapping" \
  -v "$PWD/web:/root/web" \
  luafan/luafan2-ubuntu:latest
